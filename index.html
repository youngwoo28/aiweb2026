AB 어떻게 만들었나

Vision-Language Model 기반 문서 이해 엔진

사용자가 영수증, 물류 전표, 또는 일반 문서 이미지를 업로드하고 정보 추출 프롬프트를 입력하면, 최신 비전-언어 모델(VLM)들을 통해 텍스트 및 Key-Value 데이터를 정밀하게 추출하는 AI 플레이그라운드입니다. 단일 InferenceClient를 활용해 복잡한 멀티모달 모델들의 API 호출을 자동화하고, 토큰 사용량, 레이턴시, 그리고 즉시 재현 가능한 Python 코드까지 한 화면에 시각화합니다. Docker 환경으로 패키징되어 24시간 구동되는 인프라에 배포되며, GitHub Actions CI/CD 파이프라인을 구축하여 메인 브랜치 코드 수정 시 자동으로 실시간 반영되도록 구현했습니다.
